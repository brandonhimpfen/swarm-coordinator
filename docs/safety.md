# Safety and Intended Use

swarm-coordinator is a simulation and research-prototype toolkit. It is not a flight-control system.

It does not include the safeguards required for real-world autonomous UAV operations, including certified obstacle avoidance, communications handling, airspace rules, failsafe behaviour, or hardware-level validation.

Use it for:

- Learning
- Simulation
- Research sketches
- Planning experiments
- Coordination model prototyping

Do not use it for direct real-world flight control.
